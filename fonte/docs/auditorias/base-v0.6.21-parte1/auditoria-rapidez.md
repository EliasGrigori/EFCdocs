# Auditoria de rapidez (Método Sabiá 2.1 · kit 2.1.0)

Mediana de 5 medidas por ação. Metas: ação comum até 100 ms, ação pesada até 1000 ms; com o processador mais lento, até 3 vezes isso.

| Ação | Processador | Tempo | Meta | Resultado |
|---|---|---|---|---|
| Digitar um número e Enter | normal | 50 ms | 100 ms | dentro |
| Mover a seleção | normal | 34 ms | 100 ms | dentro |
| Desfazer | normal | 34 ms | 100 ms | dentro |
| Digitar um número e Enter | 4× mais lento | 203 ms | 300 ms | dentro |
| Mover a seleção | 4× mais lento | 66 ms | 300 ms | dentro |
| Desfazer | 4× mais lento | 98 ms | 300 ms | dentro |
