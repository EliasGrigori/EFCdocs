Anonimizar planilha

Faz uma cópia da sua planilha com todos os dados trocados por dados inventados. O desenho da planilha fica igual.

Arraste a planilha para cá ou escolha o arquivo.

Esta página funciona sem internet. O arquivo é lido e trocado dentro deste computador; nada é enviado para lugar nenhum.

Trocando os dados… Planilhas grandes levam alguns segundos.

O que não muda (confira se algum nome é sensível)

    Antes de enviar a cópia

    1. Abra a cópia no Excel e olhe as abas: os textos devem estar embaralhados e os valores diferentes dos reais.
    2. Se o Excel pedir para reparar o arquivo, não envie: avise o Claude.
    3. Confira os nomes das abas e das tabelas. Se algum for sensível, troque o nome no Excel antes de enviar.
    4. Guarde o original só com você. A cópia não tem como voltar a ser o original.
